
# Personal Portfolio Site Plan

## 1. Home Page
- Introduces me and my portfolio.
- Includes a welcome message and my interests.
- Links to the Projects and About pages.

## 2. Projects/Work Page
- Showcases my projects and work.
- Includes information about my web development
  and robotics interests.

## 3. About/Contact Page
- Introduces me and my goals.
- Includes a contact section.

## Color Palette
- Green: #2E7D32
- White: #FFFFFF
- Dark gray: #333333

## Fonts
- Arial or a sans-serif font for readability.

## Navigation
All three pages will share a navigation menu
linking Home, Projects/Work, and About/Contact.
